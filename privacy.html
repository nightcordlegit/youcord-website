Politique de confidentialité

Dernière mise à jour : 29 juillet 2026

En bref

YouCord ne collecte aucune donnée personnelle. Aucun compte, aucune télémétrie, aucun suivi. L'extension et le client desktop fonctionnent exclusivement en local sur votre machine.

1. Données collectées

Aucune. YouCord ne collecte, ne stocke, ne transmet et ne partage aucune donnée personnelle ou d'utilisation. Il n'y a pas de serveur central, pas de base de données, pas d'analyseur de trafic.

Le code source est entièrement visible sur GitHub — vous pouvez vérifier qu'aucune collecte n'a lieu.

2. Permissions de l'extension navigateur

L'extension Chrome/Firefox YouCord Web déclare les permissions suivantes :

  • declarativeNetRequest — Modifier les en-têtes de réponse de Discord pour permettre l'injection du mod (suppression de la CSP). Aucune donnée réseau n'est lue ou transmise.
  • Accès hôte (*://*.discord.com/*) — Nécessaire pour injecter le script du mod dans l'interface Discord. YouCord ne lit, ne modifie et n'intercepte aucune donnée échangée.
  • Accès hôte (https://raw.githubusercontent.com/*) — Permet le chargement de ressources statiques (thèmes CSS, fichiers audio) depuis des dépôts GitHub publics. Aucune donnée personnelle n'est transmise.

3. Services tiers

YouCord interagit avec les services suivants, uniquement à votre demande explicite :

  • GitHub (github.com, raw.githubusercontent.com) — Vérification des mises à jour et téléchargement des nouvelles versions. Aucune donnée personnelle n'est envoyée.
  • Discord (discord.com) — Le client modifié se connecte à Discord comme le ferait le client officiel.

Aucun de ces services n'est utilisé pour la collecte de données par YouCord.

4. Cookies

Ce site web (youcord.fr) n'utilise aucun cookie, aucun traceur, aucun outil d'analyse. Aucun script tiers de suivi n'est chargé.

5. Partage de données

YouCord ne partage aucune donnée avec quiconque — parce que YouCord n'a aucune donnée à partager.

6. Sécurité

Les communications entre YouCord et Discord passent par le même canal chiffré (TLS) que le client officiel. Les mises à jour sont téléchargées depuis GitHub via HTTPS.

7. Vos droits

Conformément au RGPD, vous disposez d'un droit d'accès, de rectification et de suppression de vos données. Cependant, comme YouCord n'en détient aucune, ces droits sont sans objet.

8. Contact

Pour toute question relative à cette politique :

  • Discord : rejoindre le serveur
  • GitHub : ouvrir une issue
  • Telegram : @youcordoff

9. Modifications

Cette politique peut être mise à jour. La date de dernière modification est toujours indiquée en haut de cette page.
